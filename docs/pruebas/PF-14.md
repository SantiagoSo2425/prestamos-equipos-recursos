# PF-14 — Cambio de estado de recurso en uso

| Campo | Detalle |
|---|---|
| **ID** | PF-14 |
| **Requisito** | RF-35, RF-36 · US7 (prueba adicional) |
| **Método / HTTP** | PATCH /api/resources/{id}; UI /recursos/:id/editar |
| **Responsable** | Santiago (Persona A) |

**Precondiciones**: PORT-001 con préstamo ACTIVA (vencido de `est.luis`); sesión como `resp.carlos`.

**Pasos**

1. Editar PORT-001 y pasar el estado a *En revisión*.
2. Verificar con SQL que `resources.status` no cambió.
3. Editar un recurso sin préstamo activo y pasarlo a *En revisión*.

**Datos de prueba**: `{status: EN_REVISION}`.

**Resultado esperado**: Sobre PORT-001: 409 `RESOURCE_IN_USE` y el estado permanece ACTIVO. Sobre un recurso libre: 200 y estado EN_REVISION. No existe endpoint de borrado.

**Resultado obtenido**: _Pendiente: registrar tras ejecutar contra PostgreSQL con `alembic upgrade head` y `python -m app.seed` (depende del PR de Persona B)._
