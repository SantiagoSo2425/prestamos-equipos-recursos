# PF-01 — Consulta del catálogo y disponibilidad

| Campo | Detalle |
|---|---|
| **ID** | PF-01 |
| **Requisito** | RF-05, RF-06, RF-07 · CA-01 · US1 |
| **Método / HTTP** | GET /api/resources, GET /api/resources/{id}; UI /catalogo |
| **Responsable** | Santiago (Persona A) |

**Precondiciones**: Datos semilla cargados; sesión iniciada como `est.ana` (SOLICITANTE).

**Pasos**

1. Iniciar sesión como `est.ana`.
2. Abrir **Catálogo** y verificar la lista con código, nombre, categoría, estado y disponibilidad ("Indica un rango").
3. Filtrar por categoría *Portátil* y un rango de fechas futuro.
4. Marcar **Solo disponibles**.
5. Abrir el detalle de PORT-001 (con préstamo vencido) y revisar *Periodos ocupados*.

**Datos de prueba**: Categoría = Portátil; rango = mañana 08:00–12:00.

**Resultado esperado**: 200 con `Page<Resource>`. La disponibilidad coincide con los préstamos APROBADA/ACTIVA: un recurso con préstamo ACTIVO vencido aparece "Prestado" (ocupa abierto), uno con reserva APROBADA solapada "Reservado", uno EN_REVISION "No activo". Rangos contiguos `[)` no se consideran solape. El detalle lista el periodo vencido como "Hasta su devolución".

**Resultado obtenido**: _Pendiente: registrar tras ejecutar contra PostgreSQL con `alembic upgrade head` y `python -m app.seed` (depende del PR de Persona B)._

**Estado**: ⏳ Pendiente de ejecución
