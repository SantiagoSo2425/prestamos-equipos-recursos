# PF-04 — Solicitudes con datos inválidos o reglas incumplidas

| Campo | Detalle |
|---|---|
| **ID** | PF-04 |
| **Requisito** | RF-10…RF-15 · CA-02 · US2 |
| **Método / HTTP** | POST /api/loans; verificación SQL |
| **Responsable** | Santiago (Persona A) |

**Precondiciones**: Datos semilla; tokens de `est.ana`, `est.luis` (préstamo vencido) y `resp.carlos`.

**Pasos**

1. Contar filas: `SELECT count(*) FROM loans;`.
2. Enviar: fin anterior al inicio; propósito de 5 caracteres; inicio en el pasado; duración mayor al máximo de la categoría.
3. `est.ana` solicita INST-001 (solo docentes).
4. `est.luis` solicita cualquier recurso.
5. Solicitar sobre un periodo ya APROBADO de otro usuario.
6. `resp.carlos` intenta crear una solicitud.
7. Volver a contar filas.

**Datos de prueba**: Ver `docs/pruebas/prestamos.http` sección PF-04.

**Resultado esperado**: 422 `VALIDATION_ERROR` con `fields` en español (campos `end_at`, `purpose`, `start_at`); 403 `TEACHER_ONLY`; 409 `OVERDUE_BLOCK`; 409 `OVERLAP`; 403 `FORBIDDEN`. El conteo de filas en `loans` no cambia (nada se persistió). En la UI los errores aparecen por campo.

**Resultado obtenido**: Coincide con lo esperado. Ejecutado por API contra PostgreSQL 16 con la semilla; ver la sección *PF-04* de la salida del script (códigos HTTP, `code` de error y consultas SQL de verificación).
